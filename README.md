## What Is This?

A field manual built from actual troubleshooting sessions on a Windows installation that has been migrated across multiple machines, hardware generations, and OS builds — including Windows Canary (Insider) builds on jailbroken configurations. Every command and fix in here was used to solve a real problem, not copied from a textbook.

If you've ever migrated an OS and dealt with ghost devices, orphaned drivers, corrupted registry entries, or devices that just stop working — this is for you.
